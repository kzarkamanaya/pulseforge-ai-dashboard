# PulseForge Gaming — AI Support Operations Dashboard

An AI-assisted customer support dashboard built with Next.js, TypeScript, and Tailwind CSS.

This project demonstrates how gaming hardware companies can automate support workflows such as:

* ticket categorization
* severity classification
* department routing
* business policy enforcement
* customer response drafting

---

## Features

* Interactive support dashboard UI
* Ticket queue system
* AI analysis panel
* Severity badges
* Department routing
* Business policy engine
* Mock customer support environment
* Responsive modern design

---

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

---

## Business Workflow

1. Customer submits a support ticket
2. Ticket is analyzed
3. Severity level is assigned
4. Ticket routes to the correct department
5. Draft customer response is generated

---

## Local Development

Install dependencies:

npm install

Run the development server:

npm run dev

Open:
http://localhost:3000

---

## Demo Notes

The current demo uses a deterministic local analysis layer for portability and reproducible demonstrations without requiring external API keys.

The architecture is designed to support LLM/API integration.
